# Architecture documentation

The canonical cross-system reference is
[`system-design-reference.md`](system-design-reference.md). It consolidates the
complete system design and links each subsystem to its focused chapter.

Use [`system-design-traceability.md`](system-design-traceability.md) to map
architecture decisions to source paths, ADRs, and qualification targets.

Focused architecture pages exist to keep local implementation guidance close to
its owning domain. Accepted authority-changing decisions live under
`../design/` as ADRs; operational response procedures live under `../runbooks/`;
security-specific controls live under `../security/`.
