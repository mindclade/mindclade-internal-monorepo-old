# Architecture decisions

Accepted ADRs record decisions that shape dependency direction, language
ownership, runtime behavior, data integrity, and production qualification.

- Do not edit an accepted ADR to change its decision; add a superseding ADR.
- Implementation pull requests link the applicable ADRs.
- An exception to an enforced boundary requires architecture review.
- Use `rfc-template.md` for proposals that are not yet accepted.

See [decision-register.md](decision-register.md) for the complete index.
