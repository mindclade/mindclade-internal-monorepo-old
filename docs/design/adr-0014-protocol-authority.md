# ADR-0014: Explicit protocol source-of-truth matrix

- **Status:** Accepted
- **Date:** 2026-08-13
- **Scope:** Cross-language and public contracts

## Context

The platform uses Protobuf, OpenAPI, durable events, JSON projections, AsyncAPI,
configuration schemas, and generated SDKs. Hand-maintaining the same resource
in several formats would create field, enum, error, identifier, pagination, and
compatibility drift.

## Decision

- Protobuf is canonical for internal RPC, durable event envelopes, runtime
  tickets/snapshots, and worker protocols. Existing admission JSON payloads
  remain JSON-Schema-authoritative behind the typed protobuf envelope until an
  additive payload migration is completed.
- OpenAPI is canonical for the public REST surface.
- JSON Schema and AsyncAPI projections are generated or mapped explicitly where
  JSON/event catalog delivery is required.
- Configuration owns one schema per resolved configuration contract.
- Bazel owns the declared schema compilation, language-generation graph,
  compatibility tests, and provenance. Go and Python are Bazel action outputs;
  Rust is generated by the Bazel-owned Cargo build script. TypeScript is the
  one checked-in language projection because it is an independently published
  SDK input.
- Buf is pinned and invoked within that policy for STANDARD lint, FILE
  compatibility, and Protobuf-ES generation. It does not own an independent
  build graph.
- pnpm is a developer wrapper for the same pinned Buf configuration and
  clean-room verification; it is not a generation authority.
- A concept exposed in several protocols has one authoritative definition or an
  explicit mapping with compatibility tests.

## Consequences

Compatibility gates cover field removal/reuse, enum evolution, requiredness,
IDs, timestamps, pagination, idempotency, error mapping, unknown fields, event
replay, and signature canonicalization.

The machine-readable authorities are
`protocols/compatibility/protobuf-v1-descriptor.json` for the complete
descriptor surface and `protobuf-surfaces.json` for package maturity, removed
symbol tombstones, and per-RPC transport policy. A one-time breaking waiver is
valid only for the pre-release scaffold cleanup and must disappear as soon as
the comparison base includes it.

## Rejected alternatives

Independent hand-written models in every language/protocol and a single
protocol forced onto all public/internal/configuration use cases were rejected.
