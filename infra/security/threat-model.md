# Infrastructure threat model

The canonical platform threat model is `docs/security/threat-model.md`. This infrastructure projection maps those threats to Terraform, Kubernetes, GitOps, workload identity, network policy, secret management, admission control, logging, and supply-chain controls.

Materialization requires environment-specific trust boundaries, data flows, IAM and network diagrams, abuse cases, mitigations, residual risk, owners, tests, and incident/runbook links. The presence of this scaffold does not claim the infrastructure is deployed or qualified.
